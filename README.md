# 小红书内容工作台

INFJ 视角的小红书内容创作管理平台，包含每周选题、热点雷达、内容生成、数据复盘四大模块。

## 文件说明

| 文件 | 说明 |
|------|------|
| `小红书内容工作台.html` | 桌面版工作台 |
| `小红书内容工作台-手机版.html` | 手机 APP 版工作台 |

## 功能模块

- **模块A 每周选题** — 自动搜索趋势，四维评分选出本周最值得做的选题
- **模块B 热点雷达** — 评估热点与账号定位的连接度，只保留自然契合的热点
- **模块C 内容生成** — 自动生成完整小红书笔记方案（标题/正文/配图/标签/发布时间）
- **模块D 数据复盘** — 记录发布数据，自动分析有效选题、最佳发布时间、涨粉规律

## 使用方法

直接用浏览器打开 HTML 文件即可使用，无需安装任何依赖。数据保存在浏览器 localStorage 中，支持导出/导入 JSON 备份。

桌面版和手机版数据互通（共用同一套 localStorage key）。
